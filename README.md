#  Tic Tac Toe Game.

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.

## Features..

* 🎮 Two Player Mode  
* 🤖 Play Against AI Mode
* 🔄 Rematch option
* ♻️ Reset game option
* 🏆 Winner detection
* 🤝 Draw detection
* 📊 Scoreboard
* ✨ Winning cell animation
* 📱 Responsive design

##  Technologies Used..

- HTML5
- CSS3
- JavaScript
- DOM Manipulation

##  How to Play..

### 2 Players

1. Select **2 Players**.
2. Player X starts the game.
3. Players take turns clicking an empty cell.
4. The first player to get three marks in a row wins.
5. If all cells are filled without a winner, the game ends in a draw.

### Play vs AI

1. Select **Play vs AI**.
2. Player X plays first.
3. The AI plays as O.
4. Try to get three marks in a row before the AI.

##  Winning Combinations..

There are 8 possible winning combinations:

- Rows
- Columns
- Diagonals
